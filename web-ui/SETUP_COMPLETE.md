## Troubleshooting

### "Cannot find module" errors
→ Make sure you ran `npm install --legacy-peer-deps` in the web-ui folder

### Port 3000 already in use
→ Kill the process: `lsof -i :3000` then `kill -9 <PID>`

### GraphQL connection error
→ Ensure backend is running: `python graphql_server.py`

### Changes not hot-reloading
→ Restart npm: `npm start`
